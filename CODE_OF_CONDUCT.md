# Code of Conduct

Everyone interacting in a btclib-org project — its codebase, its issue
tracker, its pull requests and its discussions — is expected to follow
the [PSF Code of Conduct](https://www.python.org/psf/conduct/).

This file is kept in
[btclib-org/.github](https://github.com/btclib-org/.github) and nowhere
else, and GitHub shows it for any repository of the organization
carrying none of its own. Why it is one file rather than a copy per
repository is [section 14 of the standard][s14].

[s14]: https://github.com/btclib-org/.github#14-copied-verbatim-and-decided-per-repository
